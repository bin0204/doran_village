# 도란도란 마을 (doran_village)

조선 시대 마을에서 농사짓고, 낚시하고, 사냥하고, 이웃과 어울리면서 집과 살림을 키워 가는 생활 게임입니다.
그림과 소리까지 전부 코드로 만든, 파일 하나짜리 웹 게임이에요(바닐라 자바스크립트 + 캔버스).

## 해 보기

- `index.html`을 브라우저에서 열면 바로 시작합니다. 설치할 것은 없어요.
- GitHub Pages를 켜면(Settings → Pages → Branch `main`) 주소 하나로 어디서나 열 수 있어요.
- 진행은 그 브라우저에 자동으로 저장됩니다.

## 할 수 있는 것

| 갈래 | 내용 |
|---|---|
| 채집·농사 | 나무 베기, 바위 캐기, 과일 따기, 내 땅 어디든 밭 갈기, 계절마다 다른 작물 |
| 낚시·사냥 | 민물·바다 낚시, 들짐승 사냥, 사냥터의 범과 산삼 |
| 집 | 움막에서 솟을대문 기와집까지, 직접 못질해 짓기, 방 모양·벽지·가구 꾸미기 |
| 대장간 | 괭이·물뿌리개·도끼·곡괭이·낚싯대·활을 박자에 맞춰 두드려 벼리기 |
| 가축 | 닭장·외양간을 내 땅에 짓고 닭과 소 기르기 (달걀, 젖 짜기) |
| 이웃 | 인사·선물·부탁으로 친해지면 선물과 혜택 |
| 5일장 | 닷새마다 서는 장. 보부상에게 귀한 물건을 사고, 객주와 흥정해서 비싸게 팔기 |
| 궁궐 | 임금·중전·세자·공주가 있는 한양 궁궐, 수라간에서 요리하고 수라상 올리기 |
| 성장 | 손맛·기품·학식·무예·수완 스탯, 수라간 품계 승급, 왕실의 길(예법 수련 → 간택 → 책봉), 상인의 길(안목 겨루기·납품, 보부상 → 객주 → 거상) |
| 그 밖에 | 4계절, 도감, 한복 옷장, 낮과 밤, 비와 눈 |

## 조작

- 걷기: 방향키나 WASD, 또는 가고 싶은 곳을 누르기
- 행동: Space나 E, 또는 화면의 행동 버튼
- 자세한 설명은 게임 안의 **도움말**에 있어요.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 바로 열 수 있는 게임 (아래 원본에서 만들어 낸 것) |
| `src/doran-village.html` | 원본. 이 파일을 고칩니다 |
| `build.ps1` | 원본에서 `index.html`을 다시 만드는 스크립트 |

원본을 고친 뒤에는 아래 명령으로 `index.html`을 다시 만듭니다.

```powershell
./build.ps1
```

## 알아 둘 점

- 원본은 claude.ai 아티팩트로도 게시해 쓰고 있어요. **같이 하기**(친구가 마을에 나타나는 기능)와 **계정 저장**(다른 기기에서 이어 하기)은 아티팩트에서만 동작하고, 이 저장소의 `index.html`에서는 혼자 하기와 브라우저 저장만 됩니다.
- 글꼴(Jua, Gowun Dodum)은 Google Fonts에서 불러옵니다.
