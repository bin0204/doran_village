# 도란도란 마을 (doran_village)

조선 시대 마을에서 농사짓고, 낚시하고, 사냥하고, 이웃과 어울리면서 집과 살림을 키워 가는 생활 게임입니다.
그림과 소리까지 전부 코드로 만든, 파일 하나짜리 웹 게임이에요(바닐라 자바스크립트 + 캔버스).

## 해 보기

- `index.html`을 브라우저에서 열면 바로 시작합니다. 설치할 것은 없어요.
- GitHub Pages를 켜면(Settings → Pages → Branch `main`) 주소 하나로 어디서나 열 수 있어요.
- 진행은 그 브라우저에 자동으로 저장됩니다.
- 친구와 같이 하려면 `같이 하기` 버튼에서 방 이름을 정해 들어간 뒤, 거기 나오는 초대 주소를 친구에게 보내세요. 같은 방 이름으로 들어온 사람끼리 서로의 마을에 나타납니다.

## 조작

- 걷기: 방향키나 WASD, 또는 가고 싶은 곳을 누르기
- 행동: Space나 E, 또는 화면의 행동 버튼 (버튼의 글자가 지금 할 수 있는 일로 바뀌어요)
- 아래 단추: 가방 / 나(신분·옷장·장비) / 기록(이웃·부탁·도감·지도·길잡이) / 같이 하기 / 문의 / 설정(저장·소리·도움말·소식)
- 밭을 잘못 갈았으면 바로 뜨는 `되돌리기`(또는 Z)로 메울 수 있어요.
- 휴대폰: 왼쪽 아래 조작키로 걷고(`설정`에서 끌 수 있어요), 오른쪽 위 작은 지도를 누르면 큰 지도가 열려요. 물은 한 번 누르면 물가로 가서 바라보기만 하고, 한 번 더 눌러야 낚싯대를 던져요.
- 자세한 설명은 게임 안의 **도움말**에 있어요.

## 파일

| 파일 | 설명 |
|---|---|
| `index.html` | 바로 열 수 있는 게임 (아래 원본에서 만들어 낸 것) |
| `src/doran-village.html` | 원본. 이 파일을 고칩니다 |
| `build.ps1` | 원본에서 `index.html`을 다시 만드는 스크립트 |
| `개발노트.md` | 코드 구조, 지켜야 할 것, 테스트 방법 (이어서 개발할 때 읽는 문서) |
| `tools/` | 테스트용 페이지를 만들고 띄우는 스크립트, 공개 주소로 들어온 문의를 읽는 `asks.ps1` |

원본을 고친 뒤에는 아래 명령으로 `index.html`을 다시 만듭니다.

```powershell
./build.ps1
```

## 알아 둘 점

- 원본은 claude.ai 아티팩트로도 게시해 쓰고 있어요. **계정 저장**(다른 기기에서 이어 하기)은 아티팩트에서만 동작하고, 이 저장소의 `index.html`에서는 브라우저 저장만 됩니다.
- **같이 하기**는 여는 곳에 따라 방식이 달라요. 아티팩트에서는 공유받은 사람끼리 자동으로 만나고, 이 저장소의 `index.html`에서는 방 이름이 같은 사람끼리 공개 중계 서버를 거쳐 소식을 주고받습니다.
  - 위치·말·선물은 방 이름에서 만든 열쇠로 암호화해서(AES-GCM) 공개 Nostr 중계 서버 몇 곳에 잠깐 머무는 글(ephemeral event)로 올립니다. 웹소켓(wss, 443)만 열리면 되고, 브라우저끼리 직접 잇는 방식(WebRTC)은 쓰지 않아요.
  - 방에 들어갈 때 서명 라이브러리([@noble/secp256k1](https://github.com/paulmillr/noble-secp256k1) 3.2.0)를 jsDelivr에서 불러옵니다.
  - 방 이름을 아는 사람은 누구나 들어올 수 있으니 흔하지 않은 이름으로 정하세요.
  - 중계 서버는 다른 사람들이 운영하는 공개 서버라서, 접속한 주소(IP)와 시각은 그쪽에 보일 수 있어요. 내용은 방 이름을 모르면 읽을 수 없습니다.
- **문의**도 여는 곳에 따라 전해지는 길이 달라요. 어느 쪽이든 이름은 함께 가지 않고(판 번호·레벨·날짜만 붙어요), 다른 사람의 글은 서로 볼 수 없어요.
  - 아티팩트에서는 그 아티팩트의 저장소에 올라가고, 아티팩트 주인만 읽습니다.
  - 이 저장소의 `index.html`에서는 글을 운영자의 공개 열쇠로 잠가(secp256k1 키 합의 + AES-GCM) "같이 하기"와 같은 공개 Nostr 중계 서버 몇 곳에 보관되는 글로 올립니다. 운영자 열쇠를 가진 사람만 풀 수 있어요. 중계 서버는 다른 사람들이 운영하므로 접속한 주소(IP)와 시각은 그쪽에 보이고, 글이 얼마나 오래 보관되는지는 서버마다 다릅니다.
  - 받은 글은 문의 창 맨 아래 `운영자`에 열쇠 글자를 넣은 기기에서 보거나, `tools/asks.ps1`로 읽습니다. 저장소를 가져다 자기 게임으로 쓰려면 `./tools/asks.ps1 -NewKey`로 열쇠를 새로 만들고 원본의 `ASK_PUB`을 바꿔야 해요(열쇠 글자 파일은 저장소 밖에 생깁니다).
- 글꼴(Jua, Gowun Dodum)은 Google Fonts에서 불러옵니다.
